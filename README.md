# SQL-Student-Database
A beginner MySQL project to practice database creation and basic SQL commands using student records.
## About
This is a beginner-level MySQL project created to practice basic SQL commands.

## Objectives
- Create a database and table.
- Insert student records.
- Retrieve and filter student information.
- Update student details.
- Count and delete student records.

## Technologies Used
- MySQL
- SQL

## Topics Covered
- CREATE DATABASE
- CREATE TABLE
- INSERT
- SELECT
- WHERE
- ORDER BY
- UPDATE
- COUNT
- DELETE
